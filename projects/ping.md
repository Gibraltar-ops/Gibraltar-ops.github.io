## About the Project

A 3D first-person echo-location horror game designed for mobile platforms solely created by me with assets from the Unity storefront. Players must navigate completely dark environments by emitting sound pulses that temporarily reveal the surrounding geometry. The current version on Itch.io is a PC version converted from the mobile build.

## Key Responsibilities & Technical Implementation

- Implemented the core sonar mechanic, handling sound wave propagation and material reflection detection.
- Optimized rendering pipelines to ensure stable performance on mobile hardware.
- Designed first-person touch controls tailored for mobile navigation and interaction.
- Migrated and converted the entire codebase to work on PC for the Itch version
